## UI rules
- Players: mobile-friendly (they may read problems on a phone).
- TV page: 1080p landscape, large text, CSS-only transitions for rank changes. No login.
- Terminal panel: dark, monospace; shows loading, stdout, errors, per-test ✓/✗,
  and a final line like `Passed 3/4 tests  +15 points`. Disable the button while running.
- Handle loading, empty, and error states for every Supabase call.
